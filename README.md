## 🏗️ 莫比架構細則 (Technical Spec)

* **UI/UX**: 融入 iOS 磨砂玻璃（Backdrop Filter）美學與響應式安全區域適配。
* **Automation**: 透過 GitHub Actions 協同 Python 腳本（`auto-index.py`）實現數據與視圖的雙向同步。
* **Stack**: 基於 Vue.js 架構與精簡的 CSS 佈局，實現靜態站點的動態交互極限。
