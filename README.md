## 🚀 開始使用

### 1. 訪問網站

```
https://mobsp.qzz.io
```

### 2. 檔案管理
* **新增文章**：將 HTML 放入 `/blog/p/list/`。
* **更新配置**：編輯 `/data/config.json`。
* **管理圖示**：將 SVG 放入 `/assets/icon/svg/`，Actions 會自動處理。
