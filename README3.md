* **Android (Chrome)**: 點擊菜單 → 安裝應用

```bash
git clone [https://github.com/mobsp/mobsp.github.io.git](https://github.com/mobsp/mobsp.github.io.git)
cd mobsp.github.io
python -m http.server 8000
```
