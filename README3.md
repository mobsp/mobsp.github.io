## 🚀 開始使用

### 1. 訪問與安裝
* **網站入口**: [https://mobsp.qzz.io](https://mobsp.qzz.io)
* **iOS (Safari)**: 點擊分享 → 加入主畫面
* **Android (Chrome)**: 點擊菜單 → 安裝應用

### 2. 本地開發
```bash
# 複製儲存庫
git clone [https://github.com/mobsp/mobsp.github.io.git](https://github.com/mobsp/mobsp.github.io.git)
cd mobsp.github.io

# 啟動本地伺服器
python -m http.server 8000
