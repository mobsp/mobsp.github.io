## 🚀 **開始使用**

### 1. 訪問與安裝

* **🌐 網站入口**: https://mobsp.qzz.io
* **📱 iOS (Safari)**: 點擊分享 → 加入主畫面
* **🤖 Android (Chrome)**: 點擊菜單 → 安裝應用

### 2. 本地開發

```bash
# 複製儲存庫
git clone https://github.com/mobsp/mobsp.github.io.git
cd mobsp.github.io

# 啟動本地伺服器
python -m http.server 8000
```

### 3. 自動化維護

```bash
# 生成索引（自動掃描所有檔案）
python auto-index.py

# 查看更新日誌
git log --oneline -10

# 觸發 GitHub Actions
git push origin main
```
